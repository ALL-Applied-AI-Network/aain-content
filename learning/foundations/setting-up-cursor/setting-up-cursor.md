# Set up your coding workspace

You need two things: an editor to change a file and Python to run it. Cursor is one option, not a requirement. The exercises also work in VS Code or another editor.

## Install only what you need

Download software from its official website. On a school-managed computer, follow your school's installation policy. Do not turn off security controls to complete this lesson.

- [Cursor](https://cursor.com/downloads) includes an AI coding assistant.
- [VS Code](https://code.visualstudio.com/) is an alternative editor.
- [Python](https://www.python.org/downloads/) runs the Python examples.

AI subscriptions and API credits are separate from installing Python. Check the tool's current usage limits before enabling paid features. You can complete the initial Python exercises without a paid AI account.

## Check Python first

Open a terminal from your editor's menu.

On Windows, try:

```powershell
python --version
```

If Windows uses the Python launcher, try `py --version`. On macOS or Linux, try:

```bash
python3 --version
```

You should see Python 3 followed by a version number. If the command is not found, reopen the terminal after installation and consult the [Python setup documentation](https://docs.python.org/3/using/index.html). Use the command that works on your machine throughout the curriculum.

## Run a file

Create a folder named `ai-practice` and open that folder in your editor. Create `hello.py`:

```python
print("Hello, ALL")
```

Save it. In a terminal opened to the same folder, run `python hello.py`, `py hello.py` or `python3 hello.py`, matching the command you checked above.

The terminal should print `Hello, ALL`. Change the message and run it again.

If you see “file not found,” check the terminal's current folder and the filename. If nothing changes, save the file before running it.

## Optional: connect an AI assistant

If your editor has an assistant, ask it to explain the one line you just ran. The [current Cursor Agent guide](https://cursor.com/docs/agent/overview) describes its controls; names and shortcuts can change.

Use a practice folder without passwords, API keys or private school files. Review proposed commands before allowing an assistant to run them.
